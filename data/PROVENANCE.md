# 初始数据的来源与质量边界

- 数据包：eatwhat-core / 0.1.0；结构版本：1。
- 72 道、9 个主类别；由本项目为初始化目的编写，AI 辅助整理，尚未逐条经烹饪专家审核。
- 没有复制第三方菜谱正文、图片、菜单或营养数据；菜名为常见食物名称。
- 来源 `editorial-v1` 指向本文件，代表编辑来源，不代表外部文献验证。
- 数据按本项目 MIT 许可分发。未来外部数据保留各自的来源和许可，不能自动继承 MIT。
- 主料只记录部分常见原料；复合调料、辅料和不同做法的变化未穷尽。所有记录 `ingredients_complete=false`。
- 时间与每人食材成本是粗略编辑上限估计，未按城市、季节、份量、设备核价或实测。未知值为 null。上限不是现实履约保证。
- `regions` 暂为空，避免把流行地域错误标记成起源。以后通过有依据的地域包补充。
- `familiarity` 为演示抽样策略的编辑先验，家常标签 0.8，其他 0.5；不是人口统计热度。
- `modes` 表示常见可行用餐方式，不保证所在地有售。
- schema v1 暂不建模变体父子关系；未来变体不能只因名称相似就合并。

扩充流程：获取可分发来源 → 转换候选 → 编辑审核别名/变体 → 填已知标签 → 校验/覆盖报告 → 版本化发布。
